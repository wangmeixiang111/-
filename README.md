# -此项目为开发者预览版目前有 安卓移动端/windows桌面端
开发目的是为了解决IM和agent的连通性
移动端的目前开放安卓版本，除了支付功能需要政府牌照以外，其余核心功能基本开发完毕。可以好友之间的信息流转，好友圈，线上音视频，更支持将人与人/人与AI之间的对话一键整理成待办任务发送给桌面端的AGENT执行
桌面端AGENT目前开放WINDOWS版本，核心模式将任务分为非代码或少量代码任务和代码任务，对应的模式分别为GOWORK/GOCODE。
gowork采用了AGI好友的创新做法，让任务在和自己喜欢的虚拟角色对话中完成，更适合日常办公任务
gocode采用了主流的代码项目制，长代码任务实测均能完成，当然完成质量与模型有着必然的关系。
此项目非开源项目，不可商用，下载即可使用，但是TOKEN就几十块了，欢迎大家体验
